# thug-3ds

Неофициальный порт **Tony Hawk’s Underground** для Nintendo 3DS. Версия 0.1 основана на сборке **THUG1 0309**. В релизе исправлена нехватка памяти при воспроизведении подряд нескольких роликов. Имя в Homebrew Launcher — **THUG1 0309**. Оригинальный игровой цикл собирается для ARM11. Порт использует графический процессор PICA200, читает игровые данные с SD и воспроизводит звук и видео через библиотеки 3DS и FFmpeg.

**Для сборки нужны два входа** — установленная поддерживаемая PC-версия с каталогом `Game/Data` и законно полученные совместимые исходники движка с правом их использовать. В обычной розничной установке есть только игровые данные. Даже с оригинальным диском получить исполняемый файл 0309 по этой инструкции можно лишь при наличии второго входа. Репозиторий содержит адаптацию для 3DS и средства сборки.

## Что работает

- Free Skate, оригинальные уровни, выбор скейтера, модель, анимация и управление. В игре доступны сюжетный режим, редакторы персонажа и доски, сохранение прогресса. Полное прохождение карьеры и все сочетания одежды и трюков для 0.1 не проверены.
- Стереоскопический рендеринг с регулировкой глубины на совместимых моделях. На плотных картах скорость заметно зависит от направления камеры.
- Звуки, музыка и ролики читаются из локальной копии игры. При обычном запуске перед меню идут Activision, Neversoft и вступительный ролик. **A/B** пропускают текущий ролик, **Start** — остаток вступления.
- Личный комплект 0.1 загружает тестовое сохранение **Kevin Baskin**. При самостоятельной сборке можно начать новую игру либо подключить своё сохранение.

## На каком железе проверяли

| Модель | Подтверждённое состояние | Где начать |
|---|---|---|
| **New Nintendo 3DS / XL** | На физической New 3DS в предыдущих сборках проверены катание и стерео. У базовой 0309 есть контрольный прогон в Azahar с профилем New 3DS. В релизной 0.1 на том же профиле от начала до конца прошли три ролика, открылось меню и загрузился тестовый сейв. В Москве средний FPS на стереоповороте составил 32,5, при этом 151 из 360 кадров занял больше 33,3 мс. Для тех же оптимизаций на Манхэттене измерено 20,4 FPS в эмуляторе. Аппаратных замеров 0.1 на этих маршрутах пока нет. | Для первого сравнения подойдут School II и Москва, сначала в моно, затем в стерео. |
| **Old Nintendo 3DS / XL** | Игра выбирает профиль с меньшим бюджетом памяти и читает подготовленные ресурсы по частям. На физической Old 3DS в 0286 удалось войти в School II, Venice и Hangar. В Venice наблюдался вылет во время катания, часть других уровней не загружалась. В релизной 0.1 на профиле Old 3DS в Azahar прошли три заставки, открылось меню и загрузилось сохранение. Проверка этой версии на физической Old 3DS ещё предстоит. | **Free Skate → School II**, ползунок 3D внизу. |

В Azahar декодер прочитал все 4 288 кадров длинного интро. Для синхронизации со звуком проигрыватель пропускает часть кадров при выводе. Плавность видео на физических консолях для 0.1 ещё предстоит измерить.

## Сборка на компьютере

Рабочая конфигурация — macOS с Python **3.11+**, Git, Clang/Clang++, Make, CMake **3.20+**, Ninja и Docker с поддержкой Linux/amd64. Для исходников и временных файлов используйте локальную файловую систему. На macOS инструменты командной строки Apple предоставляют Clang и Make. Команды ниже выполняются **из корня этого комплекта**. Docker должен видеть каталог проекта. Доступ к сети нужен при первой установке инструментов и получении открытых библиотек.

**1. Подготовьте входные файлы.** Укажите путь к Git-каталогу, где лежат `Code/` и `cmake_files.cmake`, и отдельно путь к установленной немодифицированной `Game/Data`. Сборщик проверяет точное содержимое входов. Проверенные идентификаторы Git приведены ниже.

| Вход | Идентификатор |
|---|---|
| Дерево `HEAD:Code` | `fcc181d6687e66a705ab0671187e81c0d5052232` |
| Файл `HEAD:cmake_files.cmake` | `a6ab241675c2c0f7fc595e6c941c5bed2fdcd0e1` |
| FFmpeg n7.1.1 | `db69d06eeeab4f46da15030a80d539efb4503ca8` |

```sh
python3 tools/prepare_engine.py "/path/to/authorized-engine-checkout"
python3 tools/media_codec.py fetch
```

Первая команда создаёт локальное представление исходников с правками для 3DS. Вторая получает FFmpeg из официального репозитория, проверяет ревизию и готовит декодеры Bink/WAV.

**2. Соберите программу и инструменты подготовки данных.**

```sh
docker build --platform linux/amd64 -t rethpsu-sdk:0.1 .
docker run --rm --platform linux/amd64 --network none \
  -v "$PWD:/project" -w /project rethpsu-sdk:0.1 python3 build.py arm -j 4
python3 build.py host -j 4
```

ARM-сборка создаёт `build/arm/thug1_full_engine.3dsx` и `build/arm/thug1_full_engine.smdh`. Сборка на компьютере готовит инструменты для текстур, моделей и архивов уровней. Версии SDK для контрольной сборки — devkitARM r68, libctru 2.7.0, citro3d 1.7.1 и tex3ds 2.3.0. Проверены сборка образа из прилагаемого Dockerfile, его версии SDK и ARM-команда из инструкции. Dockerfile использует базовый образ devkitPro. Содержимое пакетов в его репозитории может меняться. [devkitPro Docker](https://github.com/devkitPro/docker)

**3. Соберите папку для SD.**

```sh
python3 make_sd.py --data "/path/to/THUG/Game/Data" --sdk-image rethpsu-sdk:0.1
```

Проверенный каталог PC-игры содержит 6 803 исходных файла. Скрипт проверяет их содержимое, копирует его ресурсы, извлекает недостающие изображения для редактора скейтера и готовит текстуры, упрощённую геометрию и наборы для Old 3DS. Для поддержки существующего прогресса добавьте к этой же команде параметры `--save-dir "/path/to/source-saves" --autoload "Kevin Baskin"`, подставив имя вашего сохранения из игры. Каждая сборка создаётся в новой папке. Если `out/3ds/thug1_source_engine_0309` уже существует, сначала переместите её в другое место.

**4. Запустите игру.** Скопируйте `out/3ds/thug1_source_engine_0309` в `/3ds/` на карте FAT32. Оставьте около **3 ГБ** свободного места. В Homebrew Launcher выберите **THUG1 0309**. Журнал запуска появляется рядом с игрой в `source_engine_boot.txt`. Для сообщения об ошибке укажите модель консоли, режим моно/стерео, уровень и действие перед сбоем.

### Если у вас уже установлена 0309

Перед обновлением перенесите прежнюю папку приложения в резервную копию. Скопируйте на карту полную папку 0.1. Чтобы продолжить свой прогресс, используйте свою `source-saves/` и свой `autoload_save.txt` из резервной копии. Папка 0.1 уже настроена на показ вступления. Файл `skip_opening.txt` из прежней 0309 включает пропуск роликов.
