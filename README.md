# thug-3ds

Неофициальный порт **Tony Hawk’s Underground** для Nintendo 3DS. Версия **0.1.1** соответствует сборке **THUG1 0312** в Homebrew Launcher. Оригинальный игровой цикл собирается для ARM11, графику выводит PICA200, игровые данные читаются с SD.

Для локальной сборки нужны установленная PC-версия с каталогом `Game/Data` и отдельно совместимые исходники движка, которые вы вправе использовать. Розничная установка даёт игровые ресурсы. Репозиторий содержит код адаптации для 3DS и инструменты подготовки сборки.

## Что изменилось в 0.1.1

| Консоль | Управление камерой и кнопки |
|---|---|
| **New Nintendo 3DS / XL** | Обе оси C-Stick инвертированы. Физические ZL и ZR работают как прежде. |
| **Old Nintendo 3DS / XL** | Коснитесь центральной области нижнего экрана и сдвиньте палец для поворота камеры. Отпустите палец, чтобы остановить поворот. В верхнем ряду доступны ZL, одновременное ZL+ZR и ZR, в нижнем — L3 и R3. Сенсорные кнопки можно сочетать с физическими. |

В Москве исправлено прерывание музыки вскоре после начала песни. На Old 3DS порт выделяет больше памяти движку при загрузке уровней, сохраняя отдельный резерв для графики и звука.

## Возможности и проверки

- Доступны Free Skate, сюжетный режим, выбор скейтера, редакторы персонажа и доски, сохранение прогресса и стерео с регулировкой глубины. Полное прохождение карьеры на 0312 ещё предстоит проверить.
- При запуске воспроизводятся ролики Activision, Neversoft и вступление игры. **A** или **B** пропускает текущий ролик, **Start** — оставшиеся. Для автоматической загрузки собственного сохранения предусмотрен параметр `--autoload`.
- На физической **New 3DS** исправление музыки подтверждено на 0311. В Azahar с профилем New 3DS сборка 0312 прошла 1 080 кадров катания в Москве в стерео. На плотных уровнях частота кадров зависит от направления камеры.
- В Azahar с профилем **Old 3DS** проверена загрузка сцены и коллизии School II на 0312. На 0310 в этом профиле проверено катание в School II и Venice. Для первого запуска на Old 3DS выберите **Free Skate → School II** в моно. Работа крупных уровней на этой модели ограничена памятью.
- Для 0312 прошли 20 автоматических проверок с ASan/UBSan, включая совместное использование сенсорных и физических кнопок. Проверка нового управления на физических консолях пока открыта.

## Сборка на компьютере

Рабочая конфигурация — macOS с Python **3.11+**, Git, Clang/Clang++, Make, CMake **3.20+**, Ninja и Docker с поддержкой Linux/amd64. Для исходников и временных файлов используйте локальную файловую систему. На macOS инструменты командной строки Apple предоставляют Clang и Make. Команды ниже выполняются **из корня этого комплекта**. Docker должен видеть каталог проекта. Доступ к сети нужен при первой установке инструментов и получении открытых библиотек.

**1. Подготовьте входные файлы.** Укажите путь к Git-каталогу, где лежат `Code/` и `cmake_files.cmake`, и отдельно путь к установленной немодифицированной `Game/Data`. Сборщик проверяет точное содержимое входов. Проверенные идентификаторы Git приведены ниже.

| Вход | Идентификатор |
|---|---|
| Дерево `HEAD:Code` | `fcc181d6687e66a705ab0671187e81c0d5052232` |
| Файл `HEAD:cmake_files.cmake` | `a6ab241675c2c0f7fc595e6c941c5bed2fdcd0e1` |
| FFmpeg n7.1.1 | `db69d06eeeab4f46da15030a80d539efb4503ca8` |

```sh
python3 tools/prepare_engine.py "/path/to/authorized-engine-checkout"
python3 tools/media_codec.py fetch
```

Первая команда создаёт локальное представление исходников с правками для 3DS. Вторая получает FFmpeg из официального репозитория, проверяет ревизию и готовит декодеры Bink/WAV.

**2. Соберите программу и инструменты подготовки данных.**

```sh
docker build --platform linux/amd64 -t rethpsu-sdk:0.1 .
docker run --rm --platform linux/amd64 --network none \
  -v "$PWD:/project" -w /project rethpsu-sdk:0.1 python3 build.py arm -j 4
python3 build.py host -j 4
```

ARM-сборка создаёт `build/arm/thug1_full_engine.3dsx` и `build/arm/thug1_full_engine.smdh`. Сборка на компьютере готовит инструменты для текстур, моделей и архивов уровней. Версии SDK для контрольной сборки — devkitARM r68, libctru 2.7.0, citro3d 1.7.1 и tex3ds 2.3.0. Проверены сборка образа из прилагаемого Dockerfile, его версии SDK и ARM-команда из инструкции. Dockerfile использует базовый образ devkitPro. Содержимое пакетов в его репозитории может меняться. [devkitPro Docker](https://github.com/devkitPro/docker)

**3. Соберите папку для SD.**

```sh
python3 make_sd.py --data "/path/to/THUG/Game/Data" --sdk-image rethpsu-sdk:0.1
```

Проверенный каталог PC-игры содержит 6 803 исходных файла. Скрипт проверяет их содержимое, копирует его ресурсы, извлекает недостающие изображения для редактора скейтера и готовит текстуры, упрощённую геометрию и наборы для Old 3DS. Для поддержки существующего прогресса добавьте к этой же команде параметры `--save-dir "/path/to/source-saves" --autoload "Kevin Baskin"`, подставив имя вашего сохранения из игры. Каждая сборка создаётся в новой папке. Если `out/3ds/thug1_source_engine_0312` уже существует, сначала переместите её в другое место.

**4. Запустите игру.** Скопируйте `out/3ds/thug1_source_engine_0312` в `/3ds/` на карте FAT32. Оставьте около **3 ГБ** свободного места. В Homebrew Launcher выберите **THUG1 0312**. Журнал запуска появляется рядом с игрой в `source_engine_boot.txt`. Для сообщения об ошибке укажите модель консоли, режим моно/стерео, уровень и действие перед сбоем.

### Если у вас уже есть предыдущая сборка

Установите папку `thug1_source_engine_0312` рядом с прежней. Чтобы продолжить игру, скопируйте свою папку `source-saves/` и, если он у вас есть, файл `autoload_save.txt` в папку 0312. Вступление включено по умолчанию. Файл `skip_opening.txt` в папке новой версии включает его пропуск.
